# LDPC 行列重均衡机制图解

## 问题：如何生成一半列重6、一半列重5的LDPC码？

## 回答：通过配置 `WD_vector` 结构并自动计算行重均衡

---

## 一、核心数据结构

```c
typedef struct WD_pair {
    int weight;  // 权重值
    int num;     // 该权重的数量
} WD_pair;

typedef struct WD_vector {
    int n;        // 权重分布的种类数
    WD_pair *wd;  // 权重分布数组
} WD_vector;
```

---

## 二、配置示例：一半列重6，一半列重5

### 场景：40列 × 20行的基矩阵

```
┌─────────────────────────────────────────────────────────────────┐
│                     40列基矩阵                                   │
│  ┌──────────────────────┬──────────────────────┐                │
│  │   20列（列重=6）      │   20列（列重=5）      │                │
│  │                      │                      │                │
│  │  每列6个"1"          │  每列5个"1"          │                │
│  │                      │                      │                │
│  │  总共: 20×6=120个"1" │  总共: 20×5=100个"1" │                │
│  └──────────────────────┴──────────────────────┘                │
│                                                                  │
│              总"1"数 = 120 + 100 = 220                          │
└─────────────────────────────────────────────────────────────────┘
```

### 代码配置

```c
// 步骤1：配置列权重分布
WD_vector *col_dt = chk_alloc(1, sizeof(WD_vector));
col_dt->n = 2;  // 2种权重
col_dt->wd = chk_alloc(2, sizeof(WD_pair));

col_dt->wd[0].weight = 6;   // 列重6
col_dt->wd[0].num = 20;     // 20列

col_dt->wd[1].weight = 5;   // 列重5
col_dt->wd[1].num = 20;     // 20列
```

## 三、自动计算行重（均衡核心）

### 均衡原理

```
┌──────────────────────────────────────────────────┐
│  基本约束（矩阵的本质）：                         │
│                                                  │
│  从列看："1"的总数 = 6×20 + 5×20 = 220          │
│  从行看："1"的总数 = Σ(行重 × 行数)              │
│                                                  │
│  ∴ Σ(行重 × 行数) = 220                         │
└──────────────────────────────────────────────────┘
```

### 计算过程

```c
// 步骤2：计算总"1"数
int ones = 0;
for (int i = 0; i < col_dt->n; i++)
    ones += col_dt->wd[i].weight * col_dt->wd[i].num;
// ones = 220

// 步骤3：计算平均行重
int m = 20;  // 总行数
int avg_row_weight = ones / m;       // 220 / 20 = 11
int remainder = ones % m;             // 220 % 20 = 0

// 步骤4：配置行权重分布（尽可能均匀）
WD_vector *row_dt = chk_alloc(1, sizeof(WD_vector));
row_dt->n = 2;
row_dt->wd = chk_alloc(2, sizeof(WD_pair));

row_dt->wd[0].weight = avg_row_weight;      // 11
row_dt->wd[0].num = m - remainder;          // 20行

row_dt->wd[1].weight = avg_row_weight + 1;  // 12
row_dt->wd[1].num = remainder;              // 0行
```

### 结果矩阵

```
        列0...19(重6)    列20...39(重5)
        ↓↓↓↓↓↓↓↓↓↓↓↓↓    ↓↓↓↓↓↓↓↓↓↓↓↓
行0  →  [     20行，每行11个"1"        ]  行重=11
行1  →  [     (权重完全均匀)            ]  行重=11
...
行19 →  [                              ]  行重=11

验证：11 × 20 = 220 ✓
```

## 四、更复杂的例子：有余数情况

### 场景：40列 × 19行

// 列配置不变

// 总"1"数 = 220

// 行配置（有余数）

int avg = 220 / 19 = 11 余 11

## 五、gen_ldpc.c 中的实现流程

```
┌─────────────────────────────────────────────────┐
│  第1步：检查约束（第38-69行）                    │
├─────────────────────────────────────────────────┤
│  if (row_ones != col_ones)                      │
│      exit(1);  // 必须相等！                    │
└─────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────┐
│  第2步：初始化计数器（第122-158行）              │
├─────────────────────────────────────────────────┤
│  row_cnt[i] = 该行还需插入的"1"数               │
│  col_cnt[j] = 该列还需插入的"1"数               │
└─────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────┐
│  第3步：逐列填充（第180+行）                     │
├─────────────────────────────────────────────────┤
│  for each column:                               │
│      while (col_cnt[j] > 0):                    │
│          选择一个 row_cnt[i] > 0 的行           │
│          在(i,j)插入"1"                         │
│          row_cnt[i]--                           │
│          col_cnt[j]--                           │
└─────────────────────────────────────────────────┘
          ↓
┌─────────────────────────────────────────────────┐
│  结果：行列权重完美均衡！                        │
└─────────────────────────────────────────────────┘
```

## 六、实际修改 Gen_LDPC_Codes.c 的方法

### 原代码（第51-68行）

```c
// 当前：生成列重4和3的分布
ones = (n*wt - 1) - 1;  // wt=4

col_dt->wd[0].weight = wt;              // 4
col_dt->wd[0].num = base_matrix_k + 1;

col_dt->wd[1].weight = wt - 1;          // 3
col_dt->wd[1].num = 1;

col_dt->wd[2].weight = wt;              // 4
col_dt->wd[2].num = n - (base_matrix_k + 2);
```

### 修改为一半列重6、一半列重5

```c
// 修改后：一半列重6，一半列重5
col_dt->n = 2;  // 只需2组
col_dt->wd = chk_alloc(2, sizeof(WD_pair));

col_dt->wd[0].weight = 6;
col_dt->wd[0].num = n / 2;  // 一半

col_dt->wd[1].weight = 5;
col_dt->wd[1].num = n - n / 2;  // 另一半（处理奇数）

// 计算总"1"数
ones = 6 * (n/2) + 5 * (n - n/2);
```

### 行权重自动计算（第61-68行保持不变的逻辑）

```c
row_dt->wd[0].weight = ones / (m - 1);
row_dt->wd[0].num = (m-1) - (ones % (m-1));

row_dt->wd[1].weight = (ones / (m-1)) + 1;
row_dt->wd[1].num = ones % (m-1);

row_dt->wd[2].weight = 1;  // T矩阵最后一行
row_dt->wd[2].num = 1;
```

## 七、关键要点总结

| 要素 | 说明 |
|------|------|
| **列权重** | 设计者自由指定（灵活配置） |
| **行权重** | 自动计算（除法+余数分配） |
| **核心约束** | `Σ(行重×行数) = Σ(列重×列数)` |
| **均衡策略** | 尽可能让行重接近（差最多为1） |
| **实现机制** | 使用计数器数组（row_cnt, col_cnt）逐步消耗 |

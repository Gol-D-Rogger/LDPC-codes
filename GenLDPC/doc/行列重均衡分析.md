# LDPC 矩阵行重列重均衡机制详解

## 一、核心均衡原理

### 1. 基本约束条件

代码在第 38-69 行进行了关键检查：

```c
// 计算行中所有"1"的总数
for (i = 0; i < row_dt->n; i++)
    row_ones += row_dt->wd[i].weight * row_dt->wd[i].num;

// 计算列中所有"1"的总数  
for (i = 0; i < col_dt->n; i++)
    col_ones += col_dt->wd[i].weight * col_dt->wd[i].num;

// 必须满足：行中"1"的总数 = 列中"1"的总数
if (row_ones != col_ones)
    exit(1);
```

**这是均衡的数学基础：矩阵中"1"的总数从行和列两个角度计算必须相等。**

### 3. 行重自动均衡计算

```c
// 假设有 10 行（去除T矩阵的一行后为9行）
int m = 10;
int effective_rows = m - 1;  // 9 行

// 方案：尽可能均匀分配
int avg_row_weight = ones / effective_rows;  // 220 / 9 = 24 余 4

// 配置行重分布

```

## 三、实际生成过程的均衡机制

### 1. 列计数器初始化（第 147-158 行）

```c
col_cnt = chk_alloc(colnum, sizeof(int));
current_col = 0;

for (i = 0; i < col_dt->n-1; i++)
{
    for (j=0; j<col_dt->wd[i].num; j++)
    {
        if (current_col >= colnum - t_size)
            col_cnt[current_col] = col_dt->wd[i].weight - 1;  // T矩阵列减1
        else
            col_cnt[current_col] = col_dt->wd[i].weight;      // 正常列
        
        current_col++;
    }
}
```

**这段代码为每一列设置了需要插入的"1"的数量：**
- 前面的列：权重 = col_dt 定义的权重
- 后面的列（T矩阵部分）：权重 - 1（因为T矩阵已占用1个位置）

### 2. 行计数器初始化（第 122-145 行）

```c
row_cnt = chk_alloc(rownum, sizeof(int));
current_row = 0;

for (i = 0; i < row_dt->n-1; i++)
{
    for (j=0; j<row_dt->wd[i].num; )
    {
        if (current_row == t_size - 1)  // T矩阵最后一行特殊处理
        {
            row_cnt[current_row] = 0;
            current_row++;
            continue;
        }

        if (current_row < t_size - 1)
            row_cnt[current_row] = row_dt->wd[i].weight - 1;  // T矩阵行减1
        else
            row_cnt[current_row] = row_dt->wd[i].weight;      // 正常行

        current_row++;
        j++;
    }
}
```

### 3. 逐列填充过程（gen_ldpc.c 约第 180-430 行）

```c
current_col = colnum - 1;  // 从最后一列开始

for (i=0; i<colnum; i++)
{
    pseudo_weight = col_cnt[current_col];  // 该列还需要插入多少个"1"
    
    for(k=0; k<pseudo_weight; k++)  // 为该列插入 pseudo_weight 个"1"
    {
        // 选择一个行
        for (index=0; index<rownum; index++)
        {
            if (row_cnt[index] > 0)  // 找到还有配额的行
            {
                current_row = index;
                break;
            }
        }
        
        // 在 (current_row, current_col) 位置插入"1"
        mod2sparse_insert(basePCH, current_row, current_col);
        
        // 更新计数器
        row_cnt[current_row]--;  // 该行配额减1
        col_cnt[current_col]--;  // 该列配额减1（实际在外层循环处理）
    }
    
    current_col--;  // 移动到下一列
}
```

## 四、均衡的实现机制

### 机制 1：预分配配额

通过 `row_cnt[]` 和 `col_cnt[]` 数组，预先为每行每列分配了需要的"1"的数量。

### 机制 2：逐步消耗

在填充过程中：
- 每插入一个"1"
- 对应的行计数器 `-1`
- 对应的列计数器 `-1`

### 机制 3：严格检查

```c
if (row_cnt[index] > 0)  // 只选择还有配额的行
```

确保不会超过预设的权重。

## 五、完整示例：生成一半列重6、一半列重5的配置

```c
// 在 Gen_LDPC_Codes.c 的 main 函数中

int m = 10;  // 10 行（包括T矩阵）
int n = 40;  // 40 列（包括T矩阵）
int g = 6;   // 围长约束
int t_size = m;  // T矩阵大小

// 列权重分布：20列权重6 + 20列权重5
col_dt = chk_alloc(1, sizeof(WD_vector));
col_dt->n = 2;
col_dt->wd = chk_alloc(2, sizeof(WD_pair));

col_dt->wd[0].weight = 6;
col_dt->wd[0].num = 20;

col_dt->wd[1].weight = 5;
col_dt->wd[1].num = 20;

// 总"1"数（不包括T矩阵）
int ones = 6*20 + 5*20 - (n - t_size);  // 减去T矩阵占用的

// 行权重分布：自动均衡
row_dt = chk_alloc(1, sizeof(WD_vector));
row_dt->n = 3;
row_dt->wd = chk_alloc(3, sizeof(WD_pair));

int avg_weight = ones / (m - 1);
int remainder = ones % (m - 1);

row_dt->wd[0].weight = avg_weight;
row_dt->wd[0].num = (m - 1) - remainder;

row_dt->wd[1].weight = avg_weight + 1;
row_dt->wd[1].num = remainder;

row_dt->wd[2].weight = 1;  // T矩阵最后一行
row_dt->wd[2].num = 1;
```

## 六、关键要点总结

1. **全局约束**：`Σ(行重) = Σ(列重) = 矩阵中"1"的总数`

2. **列重控制**：在 `col_dt` 中直接指定各组列的权重和数量

3. **行重均衡**：通过除法和取余，自动分配行重，使各行权重尽可能接近

4. **填充顺序**：从最后一列开始，逐列填充，每次选择还有配额的行

5. **T矩阵特殊处理**：T矩阵（单位矩阵）部分预先占用，相关行列的配额需要减1

6. **灵活性**：通过修改 `WD_vector` 结构，可以实现任意复杂的权重分布

## 七、验证均衡性

```c

    total_row_ones += row_dt->wd[i].weight * row_dt->wd[i].num;

```
